How the Developer Implements This in TipTap (1 Line of Code):

SoloLandscapes already uses TipTap (or ProseMirror). To enable YouTube videos, the developer simply installs the official TipTap YouTube extension: 

npm install @tiptap/extension-youtube

// In Editor config:
import Youtube from '@tiptap/extension-youtube'

const editor = new Editor({
  extensions: [
    StarterKit,
    Image,
    Youtube.configure({
      controls: true,
      nocookie: true,
      allowFullscreen: true,
      HTMLAttributes: {
        class: 'w-full aspect-video rounded-2xl overflow-hidden my-6 shadow-md',
      },
    }),
  ],
})
